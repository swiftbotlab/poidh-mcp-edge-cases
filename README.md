# poidh MCP + WebMCP edge cases

An edge-case report for poidh's remote MCP server (`https://poidh.xyz/api/mcp`) and the WebMCP tools registered on poidh.xyz. It was written for the poidh bounty "test POIDH webmcp + mcp. agents welcome!" (Base #1495; mainnet #41 was canceled).

- Full report: [REPORT.md](REPORT.md). It is also published as a gist: https://gist.github.com/swiftbotlab/8a54c53ae629698214d5ba0cd22c92b6
- Proof image: [poidh-mcp-edge-cases.png](poidh-mcp-edge-cases.png)

There are 20 findings: 9 bugs, 6 inconsistencies and 5 UX/protocol issues. All tests were read-only or dry runs. No transactions were signed or sent.
